title: Arnaques sur WhatsApp et Mercado Pago : comment les repérer avant de perdre de l'argent
description: Faux justificatifs, vol de compte avec le code à 6 chiffres et liens imitant Mercado Pago. Quoi surveiller et configurer dès aujourd'hui dans votre commerce.
---

Si vous vendez sur WhatsApp et encaissez avec Mercado Pago, vous êtes une cible intéressante : vous faites circuler de l'argent tous les jours, vous répondez vite et vous servez souvent plusieurs personnes à la fois. Les arnaques les plus courantes n'ont besoin de rien « pirater » : elles profitent de la précipitation.

Voici les trois que nous voyons le plus souvent dans les commerces, et comment les arrêter.

## 1. Le faux justificatif de paiement

**Comment ça marche.** Le « client » vous envoie une capture d'écran d'un virement ou d'un paiement Mercado Pago. L'image a l'air parfaite, avec le montant, la date et le numéro d'opération. Vous expédiez la commande. L'argent n'est jamais arrivé : la capture avait été retouchée.

**Comment l'arrêter.**

- **Ne confirmez jamais un paiement en regardant une capture d'écran ou un e-mail.** Ouvrez l'application Mercado Pago (ou votre banque en ligne) et cherchez l'opération dans votre activité. Si elle n'y est pas, c'est qu'elle n'existe pas.
- Méfiez-vous de l'urgence : « je vous ai déjà payé, envoyez-le maintenant, je passe le récupérer » est la phrase la plus répétée.
- Si vous utilisez Mercado Pago sur une boutique en ligne, laissez la boutique marquer elle-même la commande comme payée, à partir de la notification de Mercado Pago. Ne la marquez pas à la main.

## 2. Le vol de votre WhatsApp avec le code à 6 chiffres

**Comment ça marche.** Vous recevez un SMS avec un code WhatsApp et, en même temps, un message de quelqu'un qui se fait passer pour un fournisseur, un client ou « le support » : *« Je vous ai envoyé un code par erreur, vous pouvez me le transmettre ? »*. Ce code est celui qui permet d'enregistrer **votre numéro** sur **un autre téléphone**. Si vous le transmettez, vous perdez votre compte et ils commencent à demander de l'argent à vos contacts et à vos clients en votre nom.

**Comment l'arrêter.**

- **Le code de vérification WhatsApp ne se partage jamais, avec personne.** WhatsApp ne vous le demandera pas par chat.
- Activez la **vérification en deux étapes** : dans WhatsApp, *Ajustes → Cuenta → Verificación en dos pasos* (Paramètres → Compte → Vérification en deux étapes). Elle vous demande un code PIN à 6 chiffres que vous choisissez, et sans ce PIN, personne ne peut enregistrer votre numéro, même avec le code reçu par SMS.
- Ajoutez une adresse e-mail de récupération dans ce même menu, pour pouvoir réinitialiser le PIN si vous l'oubliez.
- Si vous utilisez WhatsApp Business sur plus d'un appareil, vérifiez de temps en temps *Dispositivos vinculados* (Appareils connectés) et déconnectez ceux que vous ne reconnaissez pas.

## 3. Le lien qui imite Mercado Pago

**Comment ça marche.** Vous recevez un e-mail ou un message disant que votre compte a été suspendu, qu'un paiement est bloqué ou que vous devez « valider vos informations ». Le lien mène à une page identique à celle de Mercado Pago, où l'on vous demande votre e-mail, votre mot de passe et, parfois, le code reçu par SMS.

**Comment l'arrêter.**

- **N'accédez pas à Mercado Pago depuis des liens.** Ouvrez l'application ou tapez l'adresse vous-même.
- Regardez l'adresse complète avant de saisir quoi que ce soit. Une fausse page peut sembler identique, mais elle ne peut pas être sur le vrai domaine.
- Activez aussi la vérification en deux étapes sur Mercado Pago et sur l'e-mail associé au compte. Si on vous vole votre mot de passe, sans le second facteur, cela ne suffit pas.

## Une checklist pour aujourd'hui

1. Vérification en deux étapes activée sur WhatsApp, Mercado Pago et l'e-mail de l'entreprise.
2. Règle interne : aucune commande ne part sans avoir vu le paiement **dans l'application**, pas sur une capture d'écran.
3. Toute l'équipe sait que le code WhatsApp ne se partage pas.
4. Personne n'accède aux comptes de paiement depuis des liens reçus par message.

Ce sont quatre changements qui se font en un après-midi et qui ferment la plupart des portes qu'utilisent les escrocs avec les petits commerces.
