Presque tous les vols de comptes que nous voyons dans les commerces commencent de la même façon : quelqu'un obtient le mot de passe (parce qu'il était réutilisé, parce qu'il a fuité ou parce qu'il a été saisi sur un faux lien) et se connecte. La **validation en deux étapes** coupe court à cela : même s'ils ont le mot de passe, pour se connecter ils ont aussi besoin de quelque chose que vous seul avez, en général un code sur votre téléphone.

Ce n'est pas infaillible, mais cela arrête la grande majorité des attaques. Et ça s'active en dix minutes.

## D'abord, quelle méthode choisir

Presque toutes les applications vont vous proposer l'une de ces options. De la plus sûre à la moins sûre :

1. **Clé d'accès ou passkey** : vous vous connectez avec l'empreinte digitale ou le déverrouillage du téléphone. Il n'y a pas de code qu'on puisse vous demander ni vous voler. Si l'application la propose, utilisez-la.
2. **Application d'authentification** (Google Authenticator, Microsoft Authenticator ou similaires) : elle génère un nouveau code toutes les 30 secondes, sur votre téléphone, sans internet. C'est la meilleure option quand il n'y a pas de passkey.
3. **Notification sur le téléphone** (« Essayez-vous de vous connecter ? ») : pratique et assez sûr, à condition de **ne pas appuyer sur « Oui » si ce n'était pas vous**.
4. **SMS** : c'est mieux que rien, mais c'est le plus faible. Si quelqu'un réussit à dupliquer votre carte SIM auprès de l'opérateur téléphonique, il reçoit vos codes.

## WhatsApp (et WhatsApp Business)

Sur WhatsApp, cela s'appelle **validation en deux étapes** et c'est un code PIN à six chiffres que vous choisissez vous-même. Il est demandé de temps en temps et, surtout, quand quelqu'un essaie d'enregistrer votre numéro sur un autre téléphone.

- Allez dans **Paramètres → Compte → Validation en deux étapes → Activer**.
- Choisissez un code PIN qui ne soit ni votre date de naissance ni « 123456 ».
- **Ajoutez une adresse e-mail** : c'est le moyen de réinitialiser le code PIN si vous l'oubliez.

C'est ce qui évite l'arnaque la plus courante : « je t'ai envoyé un code par erreur, tu peux me le transmettre ? ». Même si quelqu'un obtient ce code d'enregistrement, sans votre code PIN il ne peut pas garder le compte. Nous la racontons en entier dans [arnaques par WhatsApp et Mercado Pago](/fr/blog/estafas-whatsapp-mercado-pago).

## Gmail et le compte Google

Le compte Google est le plus important de tous : avec l'e-mail, on récupère presque tous les autres.

- Allez sur **myaccount.google.com → Sécurité**.
- Activez la **validation en deux étapes** et, si votre téléphone le permet, créez une **clé d'accès**.
- Ajoutez l'**application d'authentification** comme deuxième méthode.
- Téléchargez les **codes de secours** et gardez-les imprimés, loin de l'ordinateur.
- Sur la même page, vérifiez les **appareils connectés** et déconnectez ceux que vous ne reconnaissez pas.

## Instagram et Facebook

Les deux se gèrent depuis l'**Espace Comptes** de Meta.

- Sur Instagram : **Paramètres → Espace Comptes → Mot de passe et sécurité → Authentification à deux facteurs**.
- Choisissez le compte et la méthode : **application d'authentification** plutôt que SMS.
- Gardez les **codes de récupération** qui vous sont proposés.
- Si plusieurs personnes gèrent les réseaux, que chacune se connecte avec **son propre identifiant** depuis le portefeuille business, pas avec le mot de passe du compte principal.

Si cela vous est déjà arrivé, [on a piraté l'Instagram de mon commerce](/fr/blog/hackearon-instagram-negocio) explique pas à pas comment le récupérer.

## Mercado Pago et Mercado Libre

C'est le compte où se trouve l'argent, donc c'est celui qui mérite le plus d'attention.

- Depuis l'application : **Tu perfil → Seguridad** (« Ton profil → Sécurité » ; l'application est en espagnol et le nom exact du menu change un peu d'une version à l'autre) et activez la **verificación en dos pasos** (validation en deux étapes).
- Vérifiez les **sessions ouvertes** et les **appareils** sur lesquels votre compte est connecté.
- Mettez un code à l'ouverture de l'application et activez le déverrouillage par empreinte digitale.
- Si un employé a besoin de voir les ventes ou d'encaisser, utilisez les **autorisations du compte** ou les outils pour les équipes que propose votre formule. Ne lui donnez pas votre identifiant.

## Aussi : la banque, la boutique et le nom de domaine

La même logique s'applique à tout ce qui fait tourner votre entreprise :

- **Banque en ligne** : presque toutes les banques ont un jeton (token) ou une notification dans l'application. Activez-le.
- **Votre boutique en ligne** (Tiendanube, Empretienda, Shopify) : toutes permettent la validation en deux étapes pour le tableau de bord. Nous avons une [checklist de sécurité pour les boutiques](/fr/blog/proteger-tienda-tiendanube-empretienda).
- **Le registraire du nom de domaine et l'hébergement** : si quelqu'un y entre, il peut faire tomber votre site et vos e-mails.

## Pour ne pas vous retrouver vous-même bloqué dehors

La peur la plus courante, c'est « et si je perds mon téléphone ? ». Pour cela :

- **Gardez les codes de secours** de chaque compte, imprimés, dans un endroit sûr.
- Ayez **deux méthodes** configurées quand c'est possible (par exemple, application d'authentification + clé d'accès).
- Si vous changez de téléphone, **transférez l'application d'authentification avant** d'effacer l'ancien. La plupart ont une option pour exporter ou synchroniser.
- Tenez à jour l'**e-mail et le téléphone de récupération** de chaque compte.

## La règle qui n'a pas d'exception

**On ne transmet aucun code à personne.** Ni au « support de Mercado Pago », ni à la « banque », ni à un client, ni à une connaissance qui dit vous l'avoir envoyé par erreur. Les vraies entreprises ne vous demandent jamais ce code : si quelqu'un vous le demande, c'est une arnaque.
